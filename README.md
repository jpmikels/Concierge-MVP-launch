# The Concierge MVP

A plain-language eldercare concierge that gives adult children caring for aging parents the insider move, not a list of agencies.

## Quick Start

```bash
cd concierge
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## What's Included

- 12 curated insider answers covering real situations from the concept card
- Keyword/intent-based natural language matcher (96% accuracy on paraphrases)
- Optional LLM integration when `NEXT_PUBLIC_OPENAI_API_KEY` is set
- "Mom's file" - localStorage-based family care record
- Clean, calm UI that passes the "no platitudes" test

See `concierge/README.md` for full documentation.
